01

Situation · 배경

지난 3년간 온라인 성장은 외부 플랫폼 입점 확대로 만들어졌습니다. 매출은 커졌지만 구조적으로 두 가지 문제가 남았습니다 — 수수료 부담에 따른 낮은 수익률, 그리고 고객 데이터가 플랫폼에 귀속되어 자사에 축적되지 않는다는 점입니다.

수익 구조
자사몰의 판매 수익률은 외부 플랫폼의 수 배 수준. 동일 매출이라도 채널에 따라 이익 기여가 크게 갈림
데이터 자산
경쟁 브랜드들이 자사 고객 데이터로 상품 적중도를 높이며 성장하는 동안, 자사는 구매 데이터를 확보하지 못한 상태
과제
현재 한 자릿수에 머무는 자사몰 매출 비중을 수 배로 확대해야 하는 목표 설정 — 기존 성장 방식의 연장으로는 도달 불가

즉 자사몰은 하나의 판매 채널이 아니라, 수익률과 고객 데이터를 동시에 회수하는 구조적 과제였습니다.

02

Complication · 문제 정의

기존 접근은 신규 유입 확대에 집중돼 있었습니다. 그러나 데이터를 보면 문제는 유입량이 아니었습니다. 가입한 고객의 절반 이상이 한 번도 구매하지 않고 이탈하고 있었고, 구매 고객 대다수도 1~2회 구매 후 재방문하지 않았습니다.

밑 빠진 독에 물을 붓는 구조에서는, 유입을 늘릴수록 획득 비용만 커지고 채널은 커지지 않습니다. 따라서 문제를 "어떻게 더 데려올 것인가"에서 "온 사람이 왜 사지 않고, 왜 다시 오지 않는가"로 재정의했습니다.

Key Question

신규 유입을 늘리지 않고,
이미 온 고객만으로 채널을 성장시킬 수 있는가?

03

Hypothesis · 가설 수립

전환과 재구매가 일어나지 않는 이유를 세 개의 층위로 나눠 가설을 세웠습니다 — 누구를 위해 만들었는가(타겟), 무엇을 파는가(상품), 어떻게 사게 하는가(경험).

가설 1타겟

수익을 만드는 고객은 우리가 상정한 타겟과 다른 세그먼트일 것이다

근거

자사몰은 콜라보를 사러 오는 1020을 전제로 기획·운영돼 왔으나, 이는 방문 이미지에 근거한 가정일 뿐 구매 데이터로 검증된 바 없음

함의

타겟 가정이 틀렸다면 상품 구성·화면 구조·혜택 설계 전체가 잘못된 고객을 향해 최적화되어 있다는 뜻

검증 방식

연간 전수 구매 데이터에서 반복 구매 고객을 추출해 연령·성별·구매 품목·구매 주기 프로파일링

가설 2상품

온라인에서 실제로 팔리는 것은 신상·기획 상품이 아니라 실패 위험이 낮은 상품일 것이다

근거

온라인은 입어보고 만져볼 수 없는 채널. 구매 위험을 낮추려는 행동이 품목 선택에 반영될 것

함의

사실이라면 자사몰이 전면에 배치해야 할 상품은 화제성 상품이 아니라 반복 구매 가능한 기본 상품

검증 방식

첫 구매와 재구매의 품목 구성 변화 비교 · 반복 구매 고객의 장바구니 구성 분석

가설 3경험

이탈 원인은 상품이 아니라 탐색·비교·재구매 과정의 마찰일 것이다

근거

구매 의사가 있는 고객이 가입까지 완료하고도 구매하지 않는다면, 병목은 상품 매력도보다 구매에 이르는 과정에 있을 가능성이 큼

함의

마찰 지점을 특정해 제거하면, 추가 유입 비용 없이 전환율과 구매 빈도를 개선 가능

검증 방식

기존·비구매 고객 심층 인터뷰로 구매 여정 단계별 이탈 사유 수집 후 유형화

04

Validation · 검증

M1

전수 구매 데이터 분석

연간 구매 건 전체를 대상으로 고객·품목·구매 주기 단위 분해

M2

반복 구매 고객 심층 분석

반복 구매 고객의 구매 내역을 개별 추적해 장바구니 구성 파악

M3

고객 인터뷰

기존 고객·비구매 고객을 나눠 구매 여정 단계별 이탈 사유 수집

세 가설 모두 성립했고, 특히 가설 1은 기존 전제를 정면으로 뒤집었습니다. 자사몰의 반복 구매 고객은 1020이 아니라 3040 여성이었으며, 이들은 계절이 바뀔 때마다 연 2~3회 주기로 꾸준히 방문해 기본 상품을 구매하고 있었습니다. 객단가는 1020 대비 1.5배 수준, 연간 구매 수량도 더 많았습니다.

해석. 고객은 화제성 상품으로 유입되지만, 관계가 이어지는 순간은 기본 상품을 반복 구매할 때입니다. 그런데 자사몰 화면은 유입 상품(콜라보)을 중심으로 구성돼 있어, 정작 재구매를 만드는 상품이 잘 보이지 않는 구조였습니다.

검증 결과 · 가설 3

이탈 사유는 상품 불만이 아니라 검색·탐색·비교·재구매·혜택 인지 다섯 단계의 마찰로 유형화 → 성립

05

Insight · 마찰 지점 진단

고객 인터뷰에서 확인된 이탈 사유를 구매 여정 단계별로 배치하니, 마찰은 특정 기능의 결함이 아니라 "가족 단위로 기본 상품을 반복 구매하는 고객"을 전제하지 않은 설계에서 일관되게 발생하고 있었습니다.

단계 1탐색 — 가족 옷을 한 번에 볼 수 없다
고객이 겪는 마찰

본인·배우자·자녀 옷을 함께 보려는데 카테고리 간 이동에 여러 단계가 필요해, 매번 나갔다 다시 들어와야 함

구조적 원인

화면이 단일 고객이 자기 옷만 산다는 전제로 설계됨 — 가족 단위 구매 동선이 고려되지 않음

단계 2검색 — 고객이 쓰는 말로 찾을 수 없다
고객이 겪는 마찰

상품명을 정확히 입력해야만 결과가 나오고, 일상적으로 쓰는 표현으로 검색하면 결과가 없음

구조적 원인

검색이 내부 상품 관리 명칭 기준으로 동작 — 목적을 갖고 들어온 고객일수록 실패 경험이 큼

단계 3비교 — 기본 상품의 차이를 알 수 없다
고객이 겪는 마찰

비슷해 보이는 기본 상품이 같은 가격대로 나열돼 "뭐가 다른지 모르겠다"며 선택이 중단됨

구조적 원인

내부에는 핏·소재·기장 기준이 있지만 고객에게 비교 기준으로 제공되지 않음

단계 4재구매 — 샀던 것을 다시 사기 어렵다
고객이 겪는 마찰

매 시즌 반복 구매하는 품목인데도, 이전 구매 이력을 다시 찾아 들어가야 함

구조적 원인

구매 흐름이 신규 탐색 중심으로 설계돼, 생활 필수품형 반복 구매를 지원하는 경로가 부재

단계 5혜택 — 있는 혜택이 전달되지 않는다
고객이 겪는 마찰

혜택이 충분히 있음에도 체감하지 못해 다른 채널이 더 저렴하다고 인식

구조적 원인

신규 가입 혜택에 집중돼 기존 고객이 지금 받을 수 있는 가격이 화면에 드러나지 않음

06

Solution · 해결 설계

검증 결과를 세 개의 실행 과제로 정리했습니다. 핵심 원칙은 하나입니다 — "가족 단위로 기본 상품을 반복 구매하는 고객"을 기준으로 상품·화면·유입을 다시 배치한다.

과제 1

상품
온가족 옷장을 채우는 구성

화제성 중심 진열에서, 반복 구매가 일어나는 기본 상품 중심 구성으로 전환

과제 2

경험
다섯 마찰 지점 제거

탐색·검색·비교·재구매·혜택 각 단계의 이탈 원인을 개별 설계 과제로 전환

과제 3

유입
비용 없는 유입 경로

이미 브랜드를 아는 오프라인 매장 고객의 온라인 전환 + 동일 성향 고객이 모인 채널과 제휴

Service Design · 화면 설계

해결 방향을 실제 화면으로 옮기기 위해 정보구조 → 사용자 플로우 → 화면 단위 기능 정의 순으로 설계했습니다. 설계의 기준은 한 가지였습니다 — 한 사람이 여러 명의 옷을, 반복적으로 사는 여정을 전제로 할 것.

7-2 · 사용자 플로우

7-4 · 적용 화면

설계안을 실제 화면에 반영한 결과입니다. 두 화면 모두 "무엇을 더 보여줄까"가 아니라 "고객이 멈추는 지점을 어떻게 없앨까"를 기준으로 구성을 바꿨습니다.

화면 1홈 — 프로모션 진열에서 대상별 탐색 구조로
→
기존 구조의 문제진입 시점에 기획 상품 하나만 노출돼, 다른 대상의 옷을 보려는 고객은 스스로 경로를 찾아야 했습니다. 재구매를 만드는 기본 상품은 화면에 존재하지 않았습니다.
재설계 의도홈을 진열대가 아니라 분기점으로 정의했습니다. 대상별 탭을 상시 노출해 한 번의 조작으로 가족 구성원 간 이동이 가능하고, 상품은 단품이 아닌 착장 맥락으로 제시해 함께 담는 구매를 유도합니다.
화면 2탐색 — 다단계 메뉴에서 평면 구조로
→
기존 구조의 문제단계를 하나씩 펼쳐 내려가는 구조라 내가 찾는 상품이 어디 있는지 예측할 수 없고, 대상을 바꾸려면 상위로 되돌아가야 했습니다. 매 시즌 반복 구매하는 기능성 라인도 하위 뎁스에 묻혀 있었습니다.
재설계 의도뎁스를 걷어내고 한 화면에서 전체 카테고리를 훑을 수 있게 평면화했습니다. 상단에는 대상 탭을 두어 탐색 중 전환이 가능하고, 반복 구매율이 높은 기능성 라인은 최상단으로 승격해 찾지 않아도 보이게 배치했습니다.
